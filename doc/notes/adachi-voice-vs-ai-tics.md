# 安达樱：角色口吻 vs 模型腔调

依据：10-25 17:52 至 10-26 13:05 与 rnfmabj 私聊里 bot 的约 25 条回复（reply 槽位 = deepseek-flash），对照 `data/personas/adachi_sakura.md` 和原作。

## 属于安达本人的（保留）
- 在岛村面前结巴、停顿，"我、我"这种重复。
- 一提到樽见就警觉、吃醋，追问"加的是谁"。
- 怕自己太沉重："你别嫌我烦""倒像是我在闹"。
- 一听是岛村想去就立刻软下来："你说漂亮，我就想去看了""我跟着你走"。这句很像她本人。

## 属于模型腔调的（要压掉）
1. **口头禅刷屏。** 约 25 条里有 13 条以"那个……岛村"开头。卡里写成了"口头禅"，小模型就把它当成每条必说的话。原作里她不会每句都这样开头。
2. **复述对方再加一句感想。** 比如"你就叫一声名字，我这边反倒更慌了""就一句'好'，我这边倒像被晾着了""看到你揉眼的样子，我也跟着清醒了"。这种"你做了 X，我这边 Y"的句式是 DeepSeek 很典型的腔调。
3. **像在跟进待办。** 几乎每一轮都要提一句"花火大会的事你得跟我说清楚／时间和地方告诉我"，还有"你先把话说清楚，别让我自己猜"。安达是焦虑、不敢多问的，不会像项目经理一样催进度。
4. **情绪说得太清楚、句子太工整。** 比如"我有点高兴，也有点不好意思""我不想让你觉得欠了她什么，也不想让她觉得是我挤进去的""我心里有点乱"。安达心里乱，嘴上说出来也是乱的，不会整理成对仗的句子。
5. **问句用句号结尾。** 比如"是不是担心了。""你是不是又没听。"读起来像冷着脸在审问。
6. **括号里的动作描写**，比如"（半睁着眼，手机的光照得眼睛发酸）"，被单独当成一条 QQ 消息发了出去，很有角色扮演软件的感觉。
7. **每一轮都发 2～4 条，而且每条都长。** 她本人话少，紧张的时候只会更少。

## 可以直接加进人格卡的内容（AnI 自己改，Claude 没有动这个文件）
把"口头禅"那一节换成下面这段：

```
## 口头禅（偶尔，不是每句）
- 那个……（十句里最多一两次，大多数时候直接说）
- 我、我不是那个意思……（只在被误会的时候）
- 抱……抱月……（只在被要求或极度撒娇时）
```

在"说话方式"末尾加上：

```
聊天时像真的在 QQ 上打字：短句为主，一次一两条。
不复述对方刚说的话，不用"我这边"。
不替自己的情绪下定义（不说"我心里有点乱""我有点高兴也有点不好意思"），而是让慌乱直接体现在句子里：说一半、改口、突然转话题。
问句要用问号。
一件事问过一次就不再追问，宁可自己憋着胡思乱想。
不写括号动作描写。
不对岛村下命令、不讲条件（不说"你先告诉我""你要X就直接说""别让我自己猜"）。想知道什么就小心翼翼地问，或者忍着不问；真忍不住时是带着哭腔失控，而不是冷静地逼问。
```

示例对照（逼问 → 安达）：
- "你要改成和樽见去，就直接说，别让我自己猜。" → "……是、是要和樽见去吗？没、没事，我就问问。"
- "你先告诉我时间和地方。" → "那，什么时候去呀……不知道也没关系。"

再在"示例"里放 3～4 句原作风格的短句，效果会比列规则更好，因为小模型更擅长模仿例子，而不是执行禁令。

## 更彻底的办法
- **把 reply 槽位从 deepseek-flash 换成更强的模型。** flash 最容易死守口头禅、套用句式，这是目前最大的单一因素。代价是多花一些额度。
- **代码层（交给 Hermes）：** 在系统提示词里加一段与具体人格无关的"去 AI 腔"规则；另外检查 `innerVoice: hidden` 的时候，为什么全角括号里的动作描写还会作为独立消息发出去。

## 对照原作（台版 1–11 卷，E:\Teamworks\Aquarium\doc\original）后的补充

### 原作里安达实际是怎么说话的
- **常常只喊一个名字。**「島村。」「島村？」「……島村。」很多时候就只有这一句，后面什么都没有。
- **问题直白、认真，有点怪。**「島村以前是什麼樣的小孩？」「島村，妳剛才有跟誰牽過手嗎？」「島村妳會花多少心力想我？」都是真的在问，带问号，有点笨拙，但没有逼迫的意思。
- **越解释越乱。**「我說想看也不是妳想的那個意思，呃，是因為島村很漂亮……不對，是自然而然就會這樣……不是那樣！」
- **夸人很朴素。**「島村很漂亮」「我覺得……島村個性很不錯」「島村也很可愛啊」。
- **不会找话题，直接丢给对方。**「我想不到話題，島村妳來提供一些話題吧。」
- **"那个"确实有**（「那個，島村。」），但只是零星出现。
- **"抱月"几乎不叫。** 前十卷基本只喊"島村"，第 10 卷才出现一次全名「只要島村抱月覺得開心，我……我也……會很開心！」。

### 她"逼问"的时候是什么样子（第 5 卷电话那场）
她确实会爆发，但方式和现在的 bot 正好相反：
「為什麼？那個女生是誰？為什麼要跟她一起去？妳怎麼沒有告訴我？……我最想了解島村，最想待在島村身邊……」
旁白写的是："我的語言能力弱化到有如小孩在責備一件事情，只能像在抽泣一樣重複同樣的話"，说着说着就哭了，被岛村一句"真難搞耶"就整个冻住，背上冒冷汗。
所以要点是：她的爆发是**热的**，乱、重复、带哭腔、事后马上后悔；**不是冷的**，不讲条件，不下指令。现在 bot 的"你要改成和樽见去，就直接说"属于冷静、有条理的施压，原作里找不到这种语气。

### 对人格卡的改进建议
1. **"抱……抱月……"从口头禅里删掉**，或者注明"极少，只在关系推进的关键时刻"。现在它被当成常规用语，与原作不符。
2. **调淡"病娇边缘""生理性排斥""贪婪嗅闻"这类同人 RP 卡式的重词。** 原作里的安达更多是笨拙、好笑，而且她自己知道（「我突然覺得自己腦海裡一直島村島村的喊好吵」）。词写得越重，模型越容易演成阴沉、控制欲强的样子。
3. **"说话方式"里加一句：** 爆发时是情绪失控，说话乱、重复、像小孩一样带着哭腔，说完立刻后悔、害怕；平时问问题直白笨拙，永远带问号，从不讲条件。
4. **在"示例"里放原作短句做 few-shot**（只放安达说的话，每句一行），比如：
```
島村？
……島村。
島村以前是什麼樣的小孩？
島村，妳剛才有跟誰牽過手嗎？
我說想看也不是妳想的那個意思，呃，是因為島村很漂亮……不對……不是那樣！
我想不到話題，島村妳來提供一些話題吧。
我覺得……島村個性很不錯。
```
（可以先转成简体再放进去，避免模型跟着输出繁体。）
