# 控制台面板体验评审（2026-10-22）

评审方式：在正在运行的实例（http://127.0.0.1:5180，分支 `dev/impressions-v4` 工作区）上逐页只看只点，未保存任何设置；对照 `/mnt/project-files/design-recovery/artboards/`（SessionsV2、Main、ImpressionsV4 等）。视口 1440×900。

## 结论

“怪”主要来自三件事：

1. **同一类操作的保存方式不一致**。会话页大部分改动立刻生效，但时间表要在“编辑时段”里点“完成”，作息要点“保存作息”，表情包发送设置和人设要点“保存”。用户无法预判改完要不要再点一下。
2. **设置放在意料之外的地方**。作息（账号级）藏在“会话 → 全局默认”最底部；“要不要把这段设成积极”的建议出现在“知识”页；每日预算在总览和用量都显示，但面板里没有地方改。
3. **命名和导航分组跟内容对不上**。侧栏有“知识”和“印象”两个页面，但“知识”页里写的是“一句话印象”“它眼里的这个群”；人设页一会儿叫“人设”一会儿叫“人格”。

## 常用操作的步数

| 想做的事 | 现在的路径 | 步数 | 备注 |
|---|---|---|---|
| 全部闭嘴 | 侧栏按钮 | 1 | 好 |
| 开关某个群 | 会话 → 选群 → 开关 | 2 | 好友要多切一次 tab |
| 改某群“什么时候说话” | 会话 → 选群 → 选档 | 2 | 好 |
| 改频率限制 | 会话 → 选群 → 展开“节奏与限制” → 改数 | 3–4 | 折叠项里，摘要一长串数字 |
| 开关作息 / 改入睡时间 | 会话 → 全局默认 → 滚到底 → 改 → 保存作息 | 4–5 | 很难找到 |
| 切换人设 | 人设 → 点卡片 → 切换为此人格 | 3 | 可接受 |
| 换回复模型 | 模型 → 更换/编辑 → 对话框 → 选 → 保存 | 4–5 | 一行里“✎更换”和“编辑”两个入口 |
| 改每日预算 | 面板里做不到 | — | 只能改配置文件 |

## 问题清单（按优先级）

### P0：会让人困惑或看起来坏了

1. **“印象”页直接显示英文 `Not found`**（`#/personal-impressions`）。运行中的实例没有 `/api/view-impressions` 路由（`src/panel-server/view-impressions-routes.ts` 还没提交，实例可能是旧代码），前端把原始错误吐给用户，同时又显示“还没有整理出的个人印象”。应：404 时显示“这个功能需要重启后启用”之类的中文提示，不要两条信息同时出现；如果功能没上线就先从侧栏隐藏。
2. **保存方式统一**。会话页、表情包发送设置、人设页、作息四种保存手感。建议：开关/档位/滑杆一律即时生效并给“已保存 · 时间”回执（设计稿 SessionsV2 底部就是“改动立刻生效 · 17:02 已保存”，实现里没有回执）；长文本表单（人设）保留显式保存，但要有未保存提示。作息面板和表情包发送设置改成即时生效，去掉单独的保存按钮。
3. **作息设置位置**。现在只在“会话 → 全局默认”才渲染（`panel/src/pages/SessionsPage.tsx:204`），排在补充说明和节奏限制下面。作息是账号级的，总览“此刻”卡已经显示作息状态，应在那张卡上直接放“设置作息”入口，或在侧栏账号区放作息开关。

### P1：结构不好懂

4. **“知识”和“印象”两个导航名对不上内容**。“知识”页里有“一句话印象”“它眼里的这个群（实际注入的一行）”“好感度排序”，这些都更像印象。建议要么改名（“群与群友”/“它的看法”），要么把主观内容挪到“印象”，并在每页标题下用一句话说清两者区别。设计稿里只有一个“印象”入口。
5. **知识页选群入口重复**。顶部“选择群”下拉和左栏的群卡片做同一件事；顶部还有“群聊 / 私聊 / 所有人”tab。保留左栏一处即可。
6. **知识页把会话设置混进来**。“这个群 21:00–00:00 最热闹，要在这段设成积极吗？加入作息”会改会话时间表，但用户在知识页。建议只做一个跳到“会话 → 该群 → 时间表”的链接，或明确写“会修改会话时间表”。
7. **全局默认的标题区重复**：“所有会话 / 全局默认 / 所有会话”三行同义；“在这个群里的补充说明”“叫它的名字”在全局默认下措辞也不对。全局时改成“补充说明（全部会话）”。
8. **覆盖/继承状态看不懂**。群设置项旁的小绿点表示“被本群覆盖”，要点开菜单才能恢复继承，没有文字说明。设计稿用“未填写 · 继承全局”这类文字。建议每项右侧直接写“继承全局 / 本群覆盖 · 恢复”。顺带：“补充说明”显示“未填写”却标成被覆盖，含义冲突。
9. **时间表摘要自相矛盾**：“23:00–06:00 只在被叫时 · 其余时间只在被叫时”。两段相同时应合并显示，或提示“这个时段没有效果”。设计稿把时间轴直接摊在卡里，实现折叠了，看不到形状。
10. **会话列表信息噪音**：列表里每项显示 `2718002251:group:1004200446`，设计稿只显示群号 `1004200446 · 17 人`。账号前缀和 `group:` 对用户无意义。试聊页的会话下拉同样。
11. **侧栏账号切换器看起来能点但点不了**（单账号时 disabled，仍有上下箭头）；总览“添加新眷属 · M3 多账号”占半张卡。未上线的东西建议隐藏或缩成一行灰字。人设页“来源视图：性格演进上线后可用”“回到底色 · 性格演进上线后可用”同理。

### P2：版面与细节

12. **字太小、灰字太多**。标签 11px、说明 11–12px 的浅灰字遍布各页，1440 宽下也要凑近看。建议正文最小 13px，说明文字 12px 并提高对比度。
13. **人设页太长**：表单、实际注入预览、性格演变图、版本记录全部竖排在一页，保存按钮在顶部，改到下面要滚回去。建议保存按钮吸顶（sticky），或把“性格的变化/版本记录”放进 tab。表单每项右上角的 `## 年龄` 等 Markdown 标题提示对普通用户是噪音，可只在“源文件”视图里显示。
14. **命名不统一**：人设 / 人格（“切换为此人格”）；眷属 / 账号；“试聊与决策”页 tab 叫“决策记录”，总览链接叫“决策追踪”。选一个叫法全局替换。
15. **会话列表加载时先闪“没有找到会话。”**再出列表，应显示加载占位。
16. **模型页**：一行内同时有“✎ 更换”和“编辑”两个入口，作用重叠；mimo 的地址显示 `<待用户填写>` 原样占位符；“看图”用途绑在纯文本模型上没有任何提醒。温度/思考强度列的 `?` 提示图标与“默认”挤在一起。
17. **表情包发送设置**：“带表情回复上限 0.3 / 只发表情上限 0.1”是概率却没有 %，名字叫“上限”难懂。建议显示成 30%、10% 并写清“每次回复带图的概率”。
18. **知识页群标签全是“暂无”，但下方“实际注入的一行”有氛围内容**，两处数据看起来矛盾，需要说明注入内容从哪来。

2. P1-4 到 P1-6（导航与知识页结构，先和 AnI 确认命名）
3. 其余 P1 文案/列表清理，P2 视觉细节
