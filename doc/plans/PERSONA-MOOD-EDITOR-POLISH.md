## 1. 矩阵改紧凑（照设计稿）

现状：格子 44×44，里面印着 margin 数字，表头最小宽 54px，16 种情绪要横向滚一大截。

改成：
- 格子改成 **20×20** 的小色块，`border-spacing: 2px`，圆角 3px，**格子里不写数字**。数字放到悬停提示（`title`）和 `aria-label` 里，下方编辑区本来就有读数。
- **列头竖排**：`writing-mode: vertical-rl`，宽度跟格子一样，高度自适应（两到四个汉字）。行头去掉 `min-width: 54px`，宽度按内容，右对齐。目标是 16 种情绪时整张矩阵大约 430px 宽，不用横向滚动。情绪超过 20 种时仍然允许横向滚，保留 sticky 表头。
- **颜色**：改成按 margin 连续取色（0 → 0.3 线性映射到 `--accent-soft` 的 10%–75%），不再分三档。不允许直接切换的格子保留斜线；改过的格子保留右上角小圆点（缩成 4px）；对角线是浅灰小块。
- **悬停**：鼠标移到一个格子上时，同一行的行头和同一列的列头一起高亮，方便对准。
- **选中**：外圈 2px 描边。点格子以后，平滑滚动到上方编辑区（`scrollIntoView({block:'nearest'})`），图上同时选中这条边。
- 下方提示文案保留，「颜色越深门槛越高」改成配一条小色阶图例：易 ▁▃▅▇ 难。

## 2. 连线图好点选

截图里看到的问题：
1. 一个情绪有十几条出边，从同一点散开，细线挤在一起，很难点中想要的那条。
2. 箭头画在目标点的圆心上，箭头和点叠在一起；选中边的箭头被放得特别大。
3. 生气和害怕、感动和开心这类坐标很近的点，圆点和名字都会重叠。
4. 右下角「愉快」和「愉悦 V」画在同一个位置，叠成了「愉悦愉快」（`PersonaMoodGraph.tsx` 第 121 行和第 182 行）。区域名放在区域正中央，会压住里面的点，比如「平静」压住了「满足」。

改法：
- **主要靠点「点」来选边，不再靠点线**：
  - 没有选中「从」的时候，点一个情绪，就把它设为「从」。
  - 已经有「从」时，再点另一个情绪，就选中「从 → 它」这条边。
  - 再点「从」本身，就取消选择，回到选「从」的状态。
  - 线上的点击热区可以保留（stroke 12px）作为备用，但不再是主要入口。
  - 图上方加一行提示，随状态变化：「先点一个情绪」/「再点它要去的情绪」/「生气 → 开心」。
- **图下方加一排出边小标签**，按门槛从低到高排：`→ 开心 0.08`、`→ 惊讶 0.11` ……
  - 不允许直接切换的边用虚线边框。
  - 点标签就选中那条边。
  - 这样不碰图也能精确选。
- **线的画法**：
  - 线的两端各缩进「点半径 + 3px」，箭头停在目标点外缘。
  - 箭头 marker 统一 6×6，选中边只是加粗、变橙色，箭头不放大（`markerUnits="userSpaceOnUse"`）。
  - 没选中的出边透明度 0.35，选中的是 1。
  - 鼠标悬停在某个目标点上时，指向它的那条边临时高亮。
- **点和名字**：
  - 命中半径保持 15，但是按下时如果同时命中好几个点，选**离指针最近**的那个。
  - 名字的位置用一个简单的避让：依次试右、左、上、下四个位置，挑一个不和其他名字、其他点重叠的。
  - 文字加白色描边光晕（`paint-order: stroke; stroke: var(--surface); stroke-width: 3px`）。
  - 被选中的「从」和「到」的名字加粗。
- **拖动和点击分开**：按下以后移动超过 4px 才算拖动，否则算点击。现在轻微抖一下就会被当成拖动，点击会失效。
- **区域名和轴标签**：
  - 区域名改到各区域的左上角，字号小一号、颜色更淡。
  - 删掉重复的「愉悦 V」（第 182 行），右下只留「愉快 →」。
  - 纵轴保留「唤醒 ↑」。
