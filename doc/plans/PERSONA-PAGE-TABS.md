## 阶段 3：好感重做（参数 › 好感）

现状：`src/core/affinity/core.ts` 范围 0–100，BASELINE 50，五档 cold/cool/neutral/warm/close（20/40/60/80），`appraiseAffinityDelta = clamp(dv×20, ±3)`，每天上限 +5/−8，3 天后每天回落 1。

**新规则**：
- 范围改成 **−100..100**。
- 零上五档：不熟 / 认识 / 普通朋友 / 朋友以上 / 恋人，默认分界 15 / 35 / 60 / 85。
- 零下五档：冷淡 / 不爽 / 讨厌 / 憎恶 / 仇人，默认分界 −15 / −35 / −60 / −85。
- 「不熟」是关系坏到底之前的缓冲带。新认识的人从「不熟|认识」的分界（默认 15）起步，这个值叫「起点」。
- 久不说话时回落的目标改成起点，不再是 50。这条是我补的，AnI 没有明确反对，实现时在面板上写清楚。
- 每天上限不变。分档仍然用 `src/core/shared/hysteresis.ts` 的滞回。
- 单次变化 = 原来的 delta × 倍率(当前好感)。

**倍率曲线**（每个人设一份，存在人设 frontmatter 里，比如 `affinity:` 块）：
- 两张图：零上（0..100）和零下（−100..0）。每张图有「好感增加」「好感减少」两条曲线，用分段按钮切换。倍率范围 ×0–3，×1 是基准虚线。
- 默认曲线是光滑函数。实现参照 `Main.dc.html` 的 `knots()`，节点用 Fritsch–Carlson 单调三次插值连起来。四条默认曲线的形状：
  - 零上·增加：「不熟」里涨得慢，「认识」里涨得快，「普通朋友」开始变平，跨「朋友以上」那条线时非常难（线前大约 ×0.1），跨过去以后又变平缓。
  - 零上·减少：两头大，中间小。
  - 零下·增加：越往下越难回来，到「憎恶 / 仇人」几乎翻不了身（×0.03–0.08）。
  - 零下·减少：中段大。
  - 节点数值直接抄草图（`posGain / posLoss / negGain / negLoss`）。**重要**：默认节点固定按默认分界算，用户拖动分档线时曲线不跟着动。
- 用户编辑：
  - 按住曲线拖动，在那个位置长出一个空心圆点。它是局部偏移，影响半径 R = 0.22（按横轴比例算），所以只鼓起一小段，不会把整条线抬起来。参照 `local()`。
  - 右键点删掉。
  - 存储格式：`{ preset, points: [{x, dy}] }`。
- 分档线是可以左右拖的竖虚线。拖动只改分界，不改曲线；要保持分界的先后顺序，相邻两条至少隔 3。
- 预设：默认函数 / 平直 ×1 / 慢热。
- 图上用橙色竖线标出 AnI 当前的好感。下方有读数，比如「好感 42（普通朋友）时：每次涨 ×0.9」。

**后端改动**：
- `src/config/schema.ts` 第 182 行 `affinitySchema`：放宽范围，加 `tiers`；倍率曲线放人设里，全局配置只给默认值。

## 阶段 4：心灵能量倍率（参数 › 心灵能量）

七个滑槽，范围 ×0–3，步长 0.1。每个都显示「倍率 → 实际值」，恢复类还要显示预计恢复时间（比如「从 0.3 回到 0.8 约 2 小时 10 分」）。

| 组 | 滑槽 | 乘在哪个常量上（`src/core/mood/core.ts`） |
|---|---|---|
| 获得 | 独处恢复 | `recoverReserve` 里独处那条半衰期（inner 2h / outer 8h / mixed 4h），倍率越大恢复越快，即半衰期 ÷ 倍率 |
| 获得 | 有人陪恢复 | 有人陪那条半衰期（outer 2h / mixed 4h；inner 有人陪时现在不恢复，倍率对它不起作用，界面上要说明） |

| 消耗 | 平复代价 | `RESERVE_RECOVERY_COST` |
| 消耗 | 伤人话消耗 | 负向事件给 reserve 的增量 |

## 阶段 5：情绪库（参数 › 心情）

完整调研和理由见 Claude Docs「情绪怎么划分」（Hermes 打不开，要点都写在下面）。

**数据模型**：
- 加一个**本地情绪库**（代码里的常量），放 16 种默认情绪和默认 PAD 坐标（愉悦 V、唤醒 A、掌控 D，范围都是 −1..1）：

  | 情绪 | V | A | D | 情绪 | V | A | D |
  |---|---|---|---|---|---|---|---|
  | 兴奋 | .7 | .85 | .4 | 开心 | .6 | .55 | .3 |
  | 感动 | .6 | .6 | −.2 | 满足 | .5 | .25 | .3 |
  | 平静 | 0 | .3 | 0 | 害羞 | .2 | .6 | −.4 |
  | 惊讶 | 0 | .85 | −.2 | 无聊 | −.2 | .1 | 0 |
  | 失落 | −.5 | .25 | −.3 | 委屈 | −.5 | .5 | −.5 |
  | 心疼 | −.3 | .5 | −.1 | 吃醋 | −.4 | .6 | −.1 |
  | 烦躁 | −.4 | .65 | .2 | 焦虑 | −.4 | .75 | −.5 |
  | 害怕 | −.6 | .8 | −.7 | 生气 | −.7 | .85 | .5 |

- **边的默认值**，按库里两种情绪的坐标算：
  - `dist = hypot(dV, dA·1.5, dD·0.6)`
  - 切换门槛 `margin = 0.02 + 0.12·dist`
  - 至少停留 `dwell = 10` 分钟
  - 允许直接切换 `jump = dist < 1.45`
  - 例外：害羞→生气、满足→害怕、生气→害羞，这三条 `jump = false`。
- **人设里存的是一个情绪集合**，按名字去重。
  - 删掉库里的情绪，再加回来，坐标和边都回到库默认值。
  - 新加一个和库里同名的情绪时不阻止，但它继承库里的数据。
  - 库里没有的自定义情绪：坐标由用户在图上拖出来（新加时先放在原点附近），边按距离公式算。
  - 人设里只存和默认值不一样的部分（覆盖项）。
- **总览五档 = 愉悦×唤醒平面上的五块区域**，替换现在 `BAND_ORDER` 的 low/annoyed/calm/happy/excited：

  | 档 | 区域 |
  |---|---|
  | 不愉快 | V ≤ −0.15 且 A ≥ 0.55 |
  | 压抑 | V ≤ −0.15 且 A < 0.55 |
  | 唤醒 | V > −0.15，A ≥ 0.5，V < 0.3 |
  | 兴奋 | V > −0.15，A ≥ 0.5，V ≥ 0.3 |
  | 平静 | 其余 |

- **一个主情绪加若干副情绪**（左右脑互搏是 AnI 明确想要的）：
  - 每种情绪的强度 = `exp(−d²/(2·0.3²))`，d 是当前状态到它的 PAD 距离。
  - 主情绪按每条边各自的滞回切换。
  - 副情绪是强度 ≥ 主情绪强度 × `subTh` 的前 `subMax` 个（默认 subMax 2，subTh 0.5），可以和主情绪矛盾。

- 面板总览和心情图表：从五档换成五区域。

## 与状态机交接的对齐

两份文档改的是同一段好感和情绪计算，分工如下：本文件管**好感的范围、分档、倍率曲线**和**情绪库、主副情绪、按边滞回**；状态机那份管**模式状态机、严重事件、有疙瘩状态、随机系数**。谁后做，谁按下面的顺序接到已有代码上，不要各写一套。

**单次好感变化的计算顺序**：
1. appraise 给出基础 delta（`clamp(dv×20, ±3)`）。
2. 随机系数（状态机那份，可选，默认关）：× 0.8–1.2，种子用消息 id。
3. × 倍率曲线（本文件）：按当前好感值和增/减方向取值。
4. 有疙瘩时回升打折、封顶（状态机那份）。
5. 每日上限 +5/−8。
6. **严重事件**（状态机那份）不走 1–5，直接跳到目标值；跳的目标按本文件的新分档算（比如「掉到下一档中间」用 −100..100 的分界）。只对负面开口子。

**情绪方面**：
- 状态机那份里说的「情绪直接跳到烦躁 / 低落」，换成情绪库的名字：烦躁、失落（低落已不再是档名）。跳转时忽略边上的 dwell，但仍然要求目标情绪在集合里；用户删了它就退到最近的负面情绪。
- 随机化的换档停留时间：在每条边自己的 dwell 上乘 0.8–1.4，不再用固定的 10 分钟。
- 总览只认五区域（不愉快 / 压抑 / 平静 / 唤醒 / 兴奋），旧的低落 / 烦躁 / 平静 / 开心 / 兴奋五档名不再出现在新代码和面板里。
- 好感本身不加随机（状态机那份也是这么定的）。
