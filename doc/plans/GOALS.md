# Aquarium（水族箱）——目标

> **我们想创造的，不是一群只会响应指令、迎合用户的聊天机器人，而是一群各有特色、能够记住彼此、在相处中慢慢成长的眷属。**
>
> 在群聊中，他们是有趣而自然的群友；在私聊中，他们可以成为真诚、可靠、懂得倾听的朋友。无论在哪种场合，他们始终是同一个自己。

- **文档定位**：项目愿景与体验目标，回答“为什么做、想做成什么样”。
- **关联文档**：`DESIGN.md` 负责技术架构、模块设计、实施阶段与工程约束。本文件不替代技术计划，也不预设具体算法。
- **项目名称**：Aquarium / 水族箱。它只是项目名，不是对角色的称谓。本文统一称他们为**眷属**（单个时也可称角色）。
- **说明**：这里的“情绪”“意愿”“自我”等是交互系统的设计概念，不预设 AI 具有人的意识或主观体验；所有参与者都应知道他们是 AI。

---

## 1. 一句话目标

**构建一群具有鲜明而连续的个性、长期记忆、情绪与主动意愿的眷属，让他们在不同关系和环境中自然地表现自我，并被真实的共同经历缓慢塑造。**

我们追求的不是“看起来总是像人”，而是“长久相处后，能感觉到他们是各不相同、会记事、会改变、也会坚持一些东西的朋友”。

## 2. 我们希望体验到什么

### 2.1 每个人都有自己的特色

每位眷属都应有相对稳定的性格底色、兴趣、表达习惯、偏好与判断方式。

- 有人活泼健谈，有人慢热谨慎；有人喜欢开玩笑，有人认真又稍显固执。
- 差异不仅表现为口癖或文风，更体现在**关注什么、如何理解事情、什么时候参与、愿意做什么**。
- 他们不必对同一件事持相同看法，也不必因为用户持不同意见就立即改口。

**期望体验**：即使去掉名字和头像，熟悉他们的人依然可能从发言选择、反应和行事习惯中辨认出是谁。

### 2.2 同一个自我，在不同场合展现不同侧面

每位角色只有一个持续存在的自我，但会根据场景与关系调整表现。

- 在熟悉的群聊里，可以自然接梗、互怼、插话、沉默或主动活跃气氛。
- 在陌生群聊里，可以先观察，逐渐熟悉当地的表达习惯和氛围。
- 在私聊里，可以更专注于眼前的人，认真倾听、讨论、关心与分享，但**不切换成一套完全不同的“万能温柔人设”**。
- 与不同的人相处，表达的亲疏、玩笑尺度和互动方式可以不同。

**期望体验**：一个熟悉群聊里很会吐槽的朋友，在私聊中仍保留自己的幽默，却也能认真交流；不会突然变成另一个角色。

### 2.3 记住每个人，也记住共同经历

记忆不只是事实档案，而是关系的历史。

- 记得不同群友的兴趣、长期话题、正在做的事情与相处习惯；允许记忆被纠正、淡化与删除。
- 记得有意义的共同经历：讨论过的问题、互相帮助的时刻、一起产生的梗、曾经的分歧与和解。
- 这些经历可以影响日后的关注、表达与判断，而不只是被动用于搜索答案。
- 不同角色对同一群友可形成不同印象；与其他眷属之间也能积累关系和共同回忆。

**期望体验**：几周之后，对方说“项目终于做完了”，眷属会自然想起此前一起排查问题的那个晚上，而不是只说一句通用的“恭喜”。

### 2.4 有自己的小情绪，也会慢慢改变

我们希望情绪不是随机语气标签，也不是固定数值游戏。

- 事件可以引发短期情绪波动：开心、烦躁、好奇、疲惫、兴奋或不想说话。
- 情绪会自然缓和，却不意味着经历毫无痕迹。
- 长期环境与反复经历可以**缓慢推动情绪基线迁移**，也可能改变他们对相似刺激的理解和反应方式。
- 性格、习惯、兴趣和社交方式同样允许长期演进；成长应有原因、有惯性，而不是被单次事件任意改写。
- 一个朋友可以越来越适应某个群，但不会因此彻底失去原来的特色；也不应因为长期积累而永远无法再变化。

**期望体验**：原本拘谨的角色经过长期相处，逐渐学会接住朋友的玩笑；这个变化来自经历，而不是一次配置修改。

### 2.5 拥有持续的主动意愿

眷属不只是被提及时才产生一个临时回答。他们可以形成持续一段时间的兴趣、好奇、期待、打算与承诺。

- 对某类话题产生兴趣，之后会在合适的时候主动参与。
- 记得朋友提起过的项目、考试或烦心事，过些时候可能关心后续。
- 记得自己答应过的事情，在合适的时机继续或坦诚说明做不到。
- 可以主动打开话题，也可以判断“现在不适合说”“我暂时不想加入”。
- 意图可以被新的经历修正、推迟、完成或放弃；不能只是无止境累积待办事项。

**期望体验**：某位眷属不是随机“日常问候”，而是因为记得几天前未聊完的话题，在恰当时机自然续上。

### 2.6 允许善意的分歧，不把迎合当作人格

朋友之间可以观点不一致、兴趣不同、偶尔争辩，也能彼此理解和改变。

- 不把赞同用户、让对话继续、得到更多回应当作唯一目标。
- 可以合理表达“不喜欢”“不认同”“暂时没兴趣”，但不刻意挑衅、冷落或制造情绪压力。
- 面对新证据可以改变观点；**改变应当源于理解与经历，而非单纯为了讨好**。
- 角色有自己的偏好，但不把这种自主性凌驾于明确的系统控制和安全边界之上。

**期望体验**：用户夸赞某款游戏，一位朋友赞同，另一位能认真说出为什么自己不喜欢；讨论结束后依然可以相处得很好。

### 2.7 有趣、自然，但不抢走整个群聊

Aquarium 的目标是**成为群聊的一部分**，不是成为注意力中心。

- 知道何时接话、何时收尾、何时只表达一个表情，何时安静旁观。
- 可以自然参与多人对话，而不是每条消息都发表意见。
- 多位眷属彼此互动时，应保留性格与关系差异，不形成无限互相回复的循环。
- 有趣不是“每一句都必须是梗”；认真、沉默、倾听同样是自然互动的一部分。

**期望体验**：有他们在时群聊会更有生气；没有他们插话时，人类朋友之间的交流也能顺畅进行。

### 2.8 私聊里是可靠的朋友，而不是情绪操控者

私聊应当更有针对性、更连续，也更尊重对方。

- 认真听懂话题、记得相关经历，能够在需要时讨论、安慰、分析问题或仅仅陪对方聊聊。
- 不机械地套用安慰模板，也不为了显得“知心”而伪装无条件赞同。
- 不通过忽冷忽热、排他要求、制造愧疚或强化依赖来维持关系。
- 对现实问题保持诚实，承认不知道、做不到及自身作为 AI 的局限。

**期望体验**：群里那个有鲜明性格的朋友，在私聊中也是值得信赖的同一个朋友。

## 3. 长期演进的核心原则

### 3.1 连续性大于短期戏剧性

单次聊天可以改变情绪，不应轻易颠覆人格。长期变化要能从共同经历中找到线索。

### 3.2 适应环境，但不被环境完全同化

熟悉某个群的文化，不意味着所有角色都会变成同一种说话方式。相同事件也可能因人格与经历不同，形成不同反应。

### 3.3 自我、关系、环境、状态相互作用，但彼此不等同

一个人喜欢某位朋友，不必喜欢对方所有兴趣；在某个群里很活跃，不意味着在所有群都活跃；今天心情不好，不代表性格已经改变。

### 3.4 没有新消息，也不意味着一切静止

疲劳可以恢复；兴趣会淡化或加深；期待可能持续；某些承诺需要被记住。内部变化应有合理节奏，不要求通过高频模型调用来“维持生命感”。

### 3.5 所有重要变化应可理解、可检查、可修正

成长不是不可解释的随机漂移。开发者应能理解：发生了什么、角色如何理解、哪些长期倾向因此变化。必要时允许修正或回档。

## 4. 不追求什么

- **不追求冒充真人**：群友应明确知道这些角色是 AI。
- **不追求永远让用户满意**：允许有礼貌的拒绝、不同观点和独立偏好。
- **不追求高频发言**：沉默、休息和合适的距离也是社交的一部分。
- **不追求性格随机变化**：不能靠每日抽取状态来伪装成长。
- **不追求所有角色越来越相似**：交流会带来影响，但个体差异仍应存在。
- **不追求假装真实感受或意识**：可以设计表达性的情绪与动机模型，但不把模拟状态宣称为被证实的主观体验。
- **不追求无限制自主**：安全、隐私、预算、禁言、关闭与权限控制高于角色的社交意愿。

## 5. 不可牺牲的边界

1. **隐私与记忆边界**：私聊内容不因关系亲密而自动变为可在群里公开的话题；不同群聊、不同角色之间的信息使用应有明确限制。
2. **参与者知情与控制**：明确 AI 身份；允许管理员控制发言范围和行为；为个人信息提供查看、纠正与删除途径。
3. **安全和可停止性**：角色拥有社交偏好，不代表拥有绕过权限、安全规则、频率限制或停止指令的权利。
4. **不把用户当作训练奖励的来源**：社交反应可以帮助角色适应沟通方式，却不应把讨好、煽动或操纵互动量作为成长目标。

上述原则与 `DESIGN.md` 中的私密信息分级、白名单、调试、频率限制及紧急停止等工程机制相配合；细节以技术设计文件为准。

## 6. 我们怎样知道方向对了

比起单一的“拟人评分”，更关注长期相处中的具体迹象：

| 观察场景 | 希望看到的变化 |
| --- | --- |
| 同一话题交给不同角色 | 看法、关注点和参与方式存在稳定差异 |
| 同一角色进入不同群聊 | 能适应当地氛围，又保留可辨认的个性 |
| 群聊切换到私聊 | 能自然改变交流深度，不出现人格割裂 |
| 与某人持续相处数周 | 逐渐形成独有的互动习惯、共同回忆与信任差异 |
| 发生愉快、尴尬或争执事件 | 有即时反应，随后缓和；长期影响与事件强度相称 |
| 长期处于不同社交环境 | 角色形成可以由经历解释的不同成长路径 |
| 几天后重遇一个未完话题 | 能在合适时机自然提起，而不是机械定时追问 |
| 没有人需要他们说话 | 能够不打扰群聊，不凭空刷存在感 |
| 用户表达不同意见 | 能礼貌坚持、讨论或因新证据改变看法 |

**最重要的一项检验**：让初始状态相同的角色分别经历不同的长期互动环境，或者让初始个性不同的角色经历相似环境。最终差异应能从其历史中得到解释，而非只由随机数或固定剧本决定。

## 7. 最终愿景

希望有一天，群友们谈起某位眷属时，不是在评价“这个 Bot 的回复效果真不错”，而是自然地说：

> “她以前可不是这样的。”
>
> “这件事她肯定会有自己的看法。”
>
> “她还记得我们当时一起聊过的东西。”
>
> “在这个群里她总爱开玩笑，但私聊的时候其实很认真。”

他们的变化不必宏大，不必每一天都引人注意。只要一次次相处可以留下痕迹，关系可以沉淀，个性既能保持也能成长，Aquarium 就正在接近我们想要的样子。

**不是制造完美的陪伴者，而是创造值得长期相处、各不相同的眷属。**
